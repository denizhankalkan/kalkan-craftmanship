# Kalkan Craftsmanship

İstanbul'da ısmarlama terzilik: tüvit ceket, takım elbise ve yeniden kesim. Yalnızca randevuyla.

- Tek sayfa, bağımlılıksız HTML/CSS/JS (`index.html`)
- Hizmetler, kumaş kütüphanesi (seçilebilir kumaşlar), 4 adımlı süreç, ölçü föyü örneği, fiyat tablosu, SSS, randevu formu

## Çalıştırma

`index.html` dosyasını tarayıcıda açmak yeterli. GitHub Pages, Netlify ya da Render ile yayına alınabilir.

## Yapılacaklar

- Gerçek atölye adresi, fiyatlar ve kumaş listesi (şu an örnek)
- Atölye ve ceket fotoğrafları
- Randevu sistemi (ör. Calendly / Google Calendar) ve WhatsApp bağlantısı
- İngilizce sürüm
